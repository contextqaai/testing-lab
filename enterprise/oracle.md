# Oracle enterprise lab

**Route:** APEX sample first; Fusion/EBS separately

## What is established

Compatible APEX workspace for Customers; authorized licensed test tenant for Fusion/EBS.

The official APEX repository supplies versioned installable apps. Customers is now forked on branch 26.2. Oracle Forms may run outside the browser; the exact surface must be qualified.

## Current boundary

APEX is not Fusion ERP or EBS. No workspace import or live Oracle URL is verified.

## Proposed first exercise

Create a synthetic customer, add a contact, log activity and verify the filtered report. This is a blueprint, not an implemented tenant workflow or execution receipt.

## Access handoff

- APEX version and workspace
- Dedicated test identity/schema
- Import and public-demo permission
- Seed/reset plan
