# ServiceNow enterprise lab

**Route:** Approved demo/test instance; PDI for permitted personal learning

## What is established

ServiceNow offers Personal Developer Instances for learning, exploration and experimentation, with availability, hibernation and reclamation limits.

The PDI guide expressly excludes business/production use. For this commercial growth experiment, qualify a licensed/partner demo instance and its permitted audience instead of assuming a free PDI can be a shared marketing sandbox.

## Current boundary

No instance is allocated. A GitHub app export requires a ServiceNow runtime; it is not a self-hosted web app. No general permissive license was found on the inspected training export, so it was not rebranded or republished.

## Proposed first exercise

Proposed synthetic service request: submit, route to a test queue, update status and confirm the requester view. This is a blueprint, not an implemented tenant workflow or execution receipt.

## Access handoff

- Permitted licensed/partner demo instance
- Application/release choice
- Dedicated limited test roles
- Session expiry, reset and no outbound notifications
