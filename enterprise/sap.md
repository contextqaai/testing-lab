# SAP enterprise lab

**Route:** Fiori/CAP sample now; licensed ERP environment next

## What is established

Host the existing CAP sample; obtain an approved S/4HANA/ECC test/demo environment for ERP workflows.

The public-edition basic trial is a shared, limited exploration environment. SAP states that partners cannot use that trial for testing, demo and development. The advanced S/4HANA trial has infrastructure/hosting charges.

## Current boundary

Do not use the basic trial as the commercial testing lab. UI5/CAP is not an S/4HANA backend or Windows SAP GUI.

## Proposed first exercise

First: event registration and admin confirmation in CAP. Later: a selected synthetic purchase request in an approved ERP test tenant. This is a blueprint, not an implemented tenant workflow or execution receipt.

## Access handoff

- Choose Fiori/CAP, S/4HANA or ECC
- Approved partner/customer test landscape
- Allowed synthetic transaction
- Browser versus desktop runner qualification
